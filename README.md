# COVID-19 Tracker App for Android (MIT App Inventor)

An **Android app that tracks COVID-19 statistics**: total cases, positive cases, deaths and recoveries. Built with [MIT App Inventor](https://appinventor.mit.edu/), a block-based tool for making Android apps.

## Download

Install the prebuilt APK: [`CORODATES.apk`](CORODATES.apk)

## Files

- `CORODATES.apk`: ready-to-install Android build
- `Screen1 (1).scm`, `Screen1 (2).scm`: screen layouts
- Resource XML and manifest files from the build
